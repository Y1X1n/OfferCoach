## 0. 产品概述

OfferCoach 面向求职者：上传简历 + 目标岗位 JD，生成针对性模拟面试；文字/语音作答，AI 逐题五维评分并给出原文证据与改写建议；结束生成面试报告与改进计划。

核心闭环：**简历 × JD → 出题 → 作答 → 流式评分 → 报告 → 复盘**。

## 1. 概念模型

```text
用户 User
├── 简历 Resume（1:N，默认 1 份）
├── JD JobDescription（1:N）
├── 会话 InterviewSession（1:N）
│   ├── 题目 InterviewQuestion（1:N，含来源与检索证据）
│   ├── 回答 InterviewAnswer（每题 1 条）
│   │   └── 反馈 AnswerFeedback（1:N 版本，默认取最新）
│   └── 报告 InterviewReport（1:1）
├── 额度 UserQuota（1:1）
│   └── 流水 QuotaLedger（1:N）
└── 订阅 UserSubscription（1:N，最多 1 个 ACTIVE）

题库 QuestionBank（1:N 块）
└── 向量块 QuestionChunk（Milvus，按 question_id 聚合）

PromptTemplate（1:N）→ PromptVersion（不可变）
ABExperiment（1:N）→ ABAssignment（用户粘性分桶）
AICallLog（按调用记录，按月分区）
```

## 11. 明确不做（当前范围外）

| 事项 | 原因 |
|---|---|
| 真实企业内推 / 投递 / 猎头撮合 | 与核心价值无关，涉及合规与合作 |
| 视频面试、表情识别 | 成本高、隐私敏感；V1 只做文字/语音 |
| 多人群面、实时语音对话 | 技术复杂度与成本超 MVP |
| 简历代写、代投 | 伦理与合规风险 |
| 跨境支付、发票系统 | MVP 只做模拟支付 |
| 多租户企业版 | V2 评估 |
| 自研 LLM / 自建 GPU 推理集群 | 先用供应商 API；成本与稳定性不划算 |
