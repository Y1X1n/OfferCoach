# Security Policy

## Reporting a vulnerability

Please report security issues privately via GitHub Security Advisories for this repository. Do not open a public issue for an undisclosed vulnerability.

## Scope

- Authentication, session and quota bypass
- Prompt injection or data exfiltration through AI features
- Unauthorized access to resumes, reports or admin endpoints
- Dependency or deployment misconfiguration

We will acknowledge reports and coordinate a fix before public disclosure.
