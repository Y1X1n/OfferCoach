从简历到报告，一条完整链路

不是聊天框，而是可追踪的面试流程

01

简历解析与编辑

PDF / DOCX 上传、魔数校验、结构化字段与置信度；支持手动建档、字段修正与 Markdown / JSON / PDF 导出。

02

岗位匹配

从 JD 抽取技能、职责与岗位族，与简历逐项比对，给出匹配度、证据引用与技能缺口。

03

岗位族出题

按岗位族、关键词与维度配额召回题库；答案与参考要点优先；AI 与模板兜底，模板按项目与焦点轮换。

04

逐题场景化反馈

项目题看职责与结果，技术题看原理与取舍，行为题看冲突与复盘；异步生成后一次性展示，支持刷新恢复。

05

报告与复盘

五维雷达、亮点与风险、改进计划、逐题拆解（回答原文 + 证据 + 改写建议），支持打印为 PDF。

06

管理端与审计

题库、用户、指标、Prompt、AI 运行时配置、平台策略与审计日志；注册开关、验证码、邀请奖励与每日额度可调。

本地运行

需要 JDK 21、Maven、Node.js、pnpm、Docker

# 后端
cd backend
cp .env.example .env
docker compose up -d postgres redis
set -a; . ./.env; set +a
mvn -q -DskipTests install
mvn -pl oc-app spring-boot:run

# 前端（另一个终端）
cd frontend
pnpm install
VITE_PROXY_TARGET=http://localhost:8081 pnpm dev

从这里开始

仓库包含源码、迁移、文档与测试夹具；题库 JSONL 不随仓库分发，可用脚本重建。
